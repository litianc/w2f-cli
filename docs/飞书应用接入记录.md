日常操作优先使用 CLI。`auth scopes` 需要额外应用管理权限，可改用无需额外 scope 的官方接口检查租户授权状态：

```bash
lark-cli --profile wechat-mirror api GET /open-apis/application/v6/scopes --as bot
```

CLI 与后台的分工：

- 新增应用权限配置：当前 CLI 无对应命令，需要开发者后台；批量新增时可导入权限 JSON。
- 已配置、待管理员授权的权限：官方提供 `POST /open-apis/application/v6/scopes/apply`，可通过 `lark-cli api` 调用，但该接口没有指定新 scope 的参数，不能用于新增权限配置。
- 建群、加人、查成员与发消息：使用 `wechat-mirror` profile，通过 CLI 完成；已开通的权限不必每次操作重新申请。

官方说明：[向管理员申请授权](https://open.feishu.cn/document/application-v6/scope/apply.md)、[查询租户授权状态](https://open.feishu.cn/document/application-v6/scope/list.md)。

## 群聊邀请链接（#5，2026-09 新增）

向导内新建飞书群成功后，管理端会调用 `POST /open-apis/im/v1/chats/{chat_id}/link`（经 `lark-cli api` 原始通道，bot 身份）获取入群链接并在前端展示、可复制。

- 前提：应用具备 im 群信息写权限（im:chat 相关 scope），且机器人是群成员（建群者天然满足）；
- 权限未开通/调用失败时不阻塞建群主流程：前端降级为群名 + 「联系管理员添加成员」指引；
- 需要在飞书开放平台为应用手动开通对应权限后，链接功能才会生效（管理台无需改动）。
