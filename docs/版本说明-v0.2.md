# 微信群同步 Demo v0.2

v0.2 将单群原型扩展为本地管理台和多绑定运行时。管理台由 `python -m agents.manage` 提供 CLI 与 loopback 网页接口，SQLite 保存 Profile 引用、群映射、人员身份、确认事项、消息状态、媒体任务、租约和管理审计。

已实现：

- 多 Profile 同步、健康检查和受保护的 `feishu-mcp`/默认应用引用；凭证仍由 lark-cli 保存，项目不保存 App Secret。
- 最多 10 组有效微信群→飞书群绑定，源群 talker 与目标 chat_id 唯一，绑定级启停、暂停、恢复、归档、游标、锁和心跳。
- 人员档案、多个微信 ID 关联、按 Profile 隔离的飞书身份、未知 ID 待确认事项和飞书私聊提醒。
- 图片、视频、文件、语音和表情的 staging、上传失败占位；表情限制在 200×200 像素以内并尽量保留 GIF 动画。
- 引用消息解析：同一绑定内找到父消息时使用飞书回复，否则展示被引用发言人和可读正文。
- v0.1 SQLite/JSON 状态迁移、绑定级消息去重、姓名快照、媒体路径命名空间和管理变更记录。

常用入口：

```bash
python -m agents.manage profiles --health
python -m agents.manage bindings list
python -m agents.manage people list
python -m agents.manage status
python -m agents.manage serve
```

Codex 仍按用户指令管理 Worker；项目不配置开机启动或自动重启。正式验收先用模拟数据验证 10 组并行，再分批接入真实群。
