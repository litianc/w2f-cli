消息在飞书中显示为：

```text

```

不显示发送时间，也不添加来源标签。当前实现保留普通文字和 Unicode emoji，并对链接与引用消息做基础清洗；普通图片、视频、文件、语音仍发送类型占位文本，贴图则尝试上传原始资源并做尺寸归一化，尚未实现其他媒体的上传及媒体重试队列。
