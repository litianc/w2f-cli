# 群绑定接入模板

真实群关系、发送进度和姓名映射保存在用户数据目录的 SQLite 中。本文件不保存真实 ID；早期现场记录已移至本机 `private-docs/`。

| 项目 | 填写方式 |
| --- | --- |
| 微信账号 | 当前只读接入的 source_account |
| 源群 | 在接入引导搜索选择；保存稳定 talker |
| 目标群 | 在接入引导搜索选择；保存稳定 chat_id |
| 应用 | 明确 Profile 和 App ID，使用 bot 发送 |
| 人员 | 在人员页面确认姓名，多个微信 ID 可人工关联 |
| 首次起点 | 第一次启动时最新位置 |
| 恢复起点 | SQLite 最后完整提交的游标 |

正文格式为“姓名：正文”，不添加来源标签或时间。新建绑定先保存为待启动；修改本地显示名不会修改微信或飞书真实群名。

在项目根目录调用 `python3 -m agents.manage bindings list` 查看真实关系，调用 `python3 -m agents.manage status` 查看进度。使用 `bindings start|pause|resume|stop --id <绑定编号>` 控制单组；不要按进程名批量杀死所有 Worker。

具体安装、数据目录与控制示例见仓库 README。媒体失败和恢复标准见验收表 T41～T56。
