## Standards

两个独立审查轴按 code-review 技能执行。标准轴未发现成文规范或隐私规则违规，发现并修复：

- 原迁移入口无条件申请写锁，使慢速采集期间的状态查询可能超时。现在仅 v1 迁移申请锁、锁内复查；新增实际 CLI 并发读取回归通过。
- 判断性 Duplicated Code：三处队列行转换为事件的结构重复。现统一为 `outbox_event()`，上传内容和确认摘要使用同一转换。

标准轴复核：两项关闭，无新增发现。

## Spec

规格轴发现并修复：

- 停用设备/用户的测试可能先因其他授权原因被拒绝，形成假阳性。现在验证本人有效请求的前后变化，并断言精确的撤权错误码。
- 失败时原本只留下最终失败标志，runtime 删除后缺少关键状态。现在分阶段写 trace，保存确认、客户端前后状态、独立数据库快照与失败阶段/异常类别后再清理。
- 后续复核发现清理过程可能重新采用已复用 PID 的新创建时间。现在从本轮注册的原始 PID＋创建时间建立所有权，清理持续校验该原始时间；实际注册子进程清理测试通过。

规格轴复核：三项关闭，无新增发现；M2–M4 延期符合计划。

两轴均无未关闭发现；标准轴修复 1 个具体缺陷和 1 个维护性建议，规格轴修复 3 个验收/清理问题。
