## 2026-09-27：#3 真实邀请验收发现的问题与修复

- 现场失败：人员已关联微信身份和当前应用的飞书身份，但本人邀请该成员后只显示“群事件：群成员变更（姓名暂不可用）”。
- 根因：此前测试只覆盖旧读取器的扁平文本格式；实际 macOS 事件带群前缀和 `sysmsgtemplate` XML，模板为“你邀请 `$names$`”，成员 ID/昵称位于 `link_list/memberlist`，旧解析器没有读取。
- 修复：按 XML link 的角色解析邀请人及成员，使用稳定微信 ID 查实名和当前 Profile 下的飞书身份；隐藏撤销操作；“你”标注为“本机微信用户”，不猜测账号拥有者身份。兼容旧式模板，损坏 XML 保留可读占位。
- 自动验证：新增本人邀请、多人邀请/移出、昵称含空格与 emoji、跨账号及 Profile 隔离、损坏 XML、不重复发送测试。完整 unittest 共 135 项通过。实际失败事件只读回放已正确解析实名及当前应用的 @；未修改或补发历史消息。
- 仍待现场确认：修复加载后产生一条新的真实邀请事件，检查姓名显示和飞书客户端可点击 @。只读回放与模拟发送不替代这一步，#3 暂不判定验收通过。
