# 微信群同步 Demo v0.1

## 产品形态

这是一个运行在当前 Mac 上的单向镜像 Agent：Python worker 持续读取本地微信只读 CLI 的指定群消息，再通过独立的 `wechat-mirror` 飞书 CLI profile 转发到目标飞书群；Codex 负责按用户指令启动、停止、暂停、恢复、查询和排障。

## 已具备功能

- 绑定 `示例微信群` 微信群与 `微信群镜像同步` 飞书群。
- 普通文字、Unicode emoji、链接和基础 XML 分享消息清洗后同步。
- 每条消息带发言人姓名；已确认 ID 使用实名，未知 ID 使用微信昵称并记录待确认项。
- 表情下载后按比例限制在最大 `200×200` 像素，GIF 尽量保留动画；资源不可用时发送占位符。
- 图片、视频、文件、语音下载到本地 staging 后上传；失败时发送占位符并写入媒体任务记录。
- SQLite 保存绑定、控制状态、游标、消息状态、幂等键、媒体任务、身份映射和 worker 租约。
- 文件锁与 SQLite 租约双重防止多同步进程；心跳支持识别失联 worker。
- `start`、`stop`、`pause`、`resume`、`status` 控制接口已实现。
- 重启从 SQLite 游标恢复，已完成消息不会再次发送。

## 当前边界

- Codex 不自行常驻巡检或自动重启；用户发起管理会话后由 Codex 操作 worker。
- 飞书私聊身份确认编排、10 分钟补偿扫描、视频封面生成和完整现场验收仍属于后续迭代。
- 当前同步方向为微信到飞书单向同步。

## 验证记录

- Python 编译检查通过。
- SQLite、幂等、租约、暂停恢复、未知身份昵称回退测试通过。
- 当前 worker 可通过 `status` 查询运行状态、心跳、游标和消息统计。
