# W2F CLI · 29 秒宣传片

Remotion 工程，1920 × 1080、30 fps，H.264 + AAC。当前已交付 29 秒版（870 帧），并已替换 README 展示素材。

## 镜头

| 时间 | 内容 | 画面来源 |
| --- | --- | --- |
| 0–4 秒 | 品牌符号、W2F CLI 和核心问题 | Remotion 原创图形动画 |
| 4–13 秒 | 同一条消息从微信抵达飞书 | 用户提供的真实截图，身份信息已替换 |
| 13–18 秒 | 群映射、人员实名与运行状态 | 脱敏管理台演示界面 |
| 18–25 秒 | Codex 恢复、按序补齐、已追平 | 管理台状态与编辑层流程 |
| 25–29 秒 | 品牌收束与核心承诺 | Remotion 原创文字动画 |

聊天画面来自用户提供的两张真实截图，群名、发言人姓名、头像及机器人显示信息已替换，时间已隐去；对话与表情保留。管理台、游标和运行数字为合成演示数据。运镜、连线和说明文字是编辑层。此片将脱敏客户端截图与管理台示意画面制作成动画，并非一次实时投递的录屏，也不把镜头时长作为同步耗时证据。当前实际检查间隔为 600 秒。

`make_assets.py` 裁切已审阅的脱敏聊天截图、生成管理台演示素材，并合成原创 96 BPM 电子器乐，含和弦、拨弦音色、贝斯、鼓点及轻转场声。无旁白。中文使用系统 Hiragino Sans GB。

## 文件与复现

代码进入项目目录；工作渲染结果留在本机数据目录。用户选定的 W2F CLI 成片及其动图预览另外复制到 [`docs/media/`](../docs/media/README.md)，用于项目 README 展示。默认素材位置为 `~/.local/share/w2f-cli/promo-preview-20260913/assets`；可通过 `CHZ_PROMO_DIR` 指定另一数据目录。

```bash
cd promo
npm ci
npm run studio # 可编辑预览；读取同一个私有素材目录
python3 make_assets.py # 依赖 numpy 和 Pillow；读取已脱敏截图，生成演示素材
node render.mjs --stills
node render.mjs
```

视频生成在数据目录的 `W2F-CLI-29秒预览.mp4`，检查帧位于 `frames/`。Remotion 版本由 package-lock.json 固定。`src/preview.tsx` 中可编辑文案、时间和动画。

`make_assets.py` 仅从 `docs/media/wechat-sanitized.png` 和 `feishu-sanitized.png` 读取聊天截图，生成 `wechat-real-chat.png`、`feishu-real-chat.png`；缺少输入则停止。`overview.png` 和 `progress-crop.png` 使用合成数据。脚本不连接微信数据库或飞书群。

`sanitize_captures.py --wechat <原始微信截图> --feishu <原始飞书截图>` 可重建脱敏图，输入必须位于仓库外。当前坐标模板只支持这两张截图的尺寸；其他截图须重新定位并审阅。替换直接写入新 RGB 像素，去除原始元数据，不保留可撤销图层。姓名统一为“小林 / 小周”，个人头像改为文字头像，群名改为“产品协作群 / 产品协作镜像”。渲染只读取最终脱敏图。

## 29 秒完整分镜

用户已确认借鉴 [Remotion Recorder Showcase](https://www.remotion.dev/showcase#HCA9phm4tUVjYm9dFWj1GpYTwIGrse00yg01SwaM2PbJU) 的开场方向：留白、集中呈现品牌符号和大标题，再进入实际产品画面。设计使用 W2F CLI 自身标识、文案及原创动画。

| 时间 | 画面 | 主要文案与目的 |
| --- | --- | --- |
| 0–4 秒 | 小型箭头变为两端对话气泡，出现 W2F CLI；品牌出现后转入聊天画面 | “重要消息，不该只停在一个群里。”建立共鸣 |
| 4–13 秒 | 跟随同一段脱敏演示会话从微信到飞书，依次突出正文、可用媒体、发送人姓名 | “内容接得上，谁说的也清楚。”只展示一条连贯的消息路径 |
| 13–18 秒 | 脱敏管理台聚焦群映射、实名与运行状态；使用局部推进保持文字可读 | “群与人，统一管理。”展示可控制的产品形态 |
| 18–25 秒 | 用户指令 → Codex 恢复服务 → 按序补齐 → 已追平 | 明确呈现 Codex 的控制职责，用明确标注的演示状态说明恢复流程 |
| 25–29 秒 | 两端气泡收拢到品牌标识，画面留白、音乐收束 | “让重要的话，抵达需要的人。”与 W2F CLI 同屏，停留至结束 |

剪辑要求：

- 成片目标 29 秒，含全部转场和片尾；封装后总时长也不得超过 30 秒。保持 1080p、30 fps。
- 每个镜头集中说明一件事。文案随镜头出现，关键句完整停留，避免快速逐字闪烁和密集功能罗列。
- 配乐采用温暖的键盘或拨弦音色配轻电子节奏，恢复过程先收弱再展开，结尾自然结束。
- 只使用审阅过的脱敏截图和演示画面；恢复过程若加速，标注“过程加速”；模拟过程必须标为演示，不把示意数字当作真实运行状态。
- 正常检查间隔按实际配置说明，不以剪辑时长暗示秒级同步。普通图片兼容性和视频号跳转仍按实测结果展示。
- README 已替换为 29 秒版；替换展示素材前须重新复核画面和校验值。

渲染方式参考 [Remotion 官方渲染文档](https://www.remotion.dev/docs/cli/render)。
